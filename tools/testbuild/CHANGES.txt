Alamo engine test build, 2026-11-18
====================================

How to run
----------
- Play.exe       Double-click to play: Forces of Corruption, no mod, without a console window. Pick
                 a mod in the game (main menu, Mods), or drop a mod folder onto Play.exe. Only an
                 error shows a window, offering the log (alamo_game_log.txt).
- Play.cmd       The same with a console window. Log: alamo_game_log.txt.
- Play_Mod.cmd   Any mod. Double-click it for a menu of every mod installed on this PC:
                 Steam workshop items (subscribed mods) and folders in corruption\Mods.
                   type a number      play that mod (Enter alone plays your last pick again)
                   C and a number     check a mod without playing: loads it the way the game does and
                                      opens a report (mod_check.txt): missing files, campaigns, scripts,
                                      shaders, assets, and an overall grade. Run this first if a mod
                                      will not start.
                   a+b (e.g. 7+1)     play mod a on top of mod b (a submod on the mod it needs).
                                      Submods whose modinfo.json names the mod they need are stacked on
                                      their own; the menu shows "(on top of 1)".
                   F                  a mod folder somewhere else
                 Or drag a mod folder (the one holding its Data folder) onto Play_Mod.cmd.
- command-center.exe   The Command Center launcher: profiles, mods and Steam Workshop items,
                 saves, graphics options, unit data, the campaign map and diagnostics in one
                 window. It starts alamo_game.exe from this folder. Subscribing, unsubscribing and
                 updating open the item in the Steam client; searching the Workshop opens in Steam
                 too, unless you add your own Steam Web API key under Settings.
- In the game: the main menu's Mods button lists the same mods, checks the one you select and
  restarts the game with it.

The launchers find the game through Steam on their own. If they cannot, they ask once for the
"corruption" folder and remember it in game_path.txt.

Each mod gets its own folder under mod_runs (named after the mod: ws<workshop id> or local_<folder>)
with its shader cache, its saves, log.txt and mod_check.txt, so mods never mix saves. Please send
that log.txt with any report. The first start of a mod builds its shader cache, so it is slower.
The base game keeps its saves in %LOCALAPPDATA%\alamo\Saves.

If the game crashes (new in this build), it writes a crash dump to %LOCALAPPDATA%\alamo\crashes
(a .dmp and a .txt with the same name). Please send both with the log; they only help with this
exact build.

What to try
-----------
NEW in this build (please check each one in game):
- Squadrons are back to the original sizes and prices (the 12-ship squadrons of the last build
  are gone). The FIGHTERS / BOMBERS wing buttons and F2 / F3 stay.
- Skirmish setup: more than two players, with teams and a separate AI difficulty per slot; the
  advanced skirmish options (credits, win condition, heroes, super weapons, pre-built base,
  starting units) now reach the battle. Empty slots and the profile's faction are handled as in
  the original. Please try a 3- or 4-player land and space skirmish.
- Land skirmish AI: Empire against Underworld no longer stalls ("not a valid destination for
  TaskForce MainForce" should be gone); the AI now uses the original's rules for task forces,
  build pads, start structures and target choice, in land and space.
- Battles autosave at their start ([AutoSave] row in the Load list); Retry on the battle-end
  screen loads it.
- Story and tutorial: story text lines, advisor hints, tutorial pointers and highlights, script
  fades, letterbox, cinematic and scripted camera moves, control locks; the text crawl over
  full-screen movies; story rewards in galactic, tutorial, Underworld and tactical missions.
  Please play the start of the tutorial and of a story campaign.
- Space: hardpoint turrets now turn toward their target before they fire; a destroyed hardpoint
  drops its attached model and breakoff debris; retreating ships fly their jump-out.
- Land: indigenous spawners, the Magnepulse fire-at-position, gravity control fields.
- Effects: weather visuals, blob shadows under units, selection circles that follow the ground
  slope, ability and status particles, drain bolts, the heal range blob, stun and shield
  penetration effects. Ability, base shield, build pad and capture point animations play.
- Sound: battle sounds (weather, combat, ability activation), galactic sounds, super-weapon
  and lose music, garrison sounds, clash speech; dialog sounds as in the original.
- Galactic: the FoC base layout planet map; summary sort keys; the Hints check box turns every
  advisor hint on or off; galactic messages show as advisor lines.
- Menus: the Multiplayer button is gone from the main menu (multiplayer is out of scope); key
  capture, movie captions and tooltip placement as in the original; save paths with non-English
  characters work.
- Smoother play: the 110-230 ms hitches every few seconds and the slow memory growth (about
  half a GB per minute) are fixed; better frame times on many-core CPUs.
- Mods: the Command Center and the mod picker play a mod together with the mods it needs
  (its stack), refuse mods made for plain Empire at War, and warn about missing text languages.
  Mods with damaged models, animations or textures that the original still draws now load too.
  Fall of the Republic: its news plugin no longer stops at the first conquest.
Still worth checking from earlier builds:
- Command Center: starting the game from it with and without a mod.
- Options: Display and Graphics pages, Display Mode, UI Scale, Render Scale, the anti-aliasing
  list (Off, SMAA, TAA, MSAA 2x / 4x / 8x, five FSR modes; the log names the FSR version).
- Fleet cohesion (O), unit path lines, fleet and ship names, the Save / Load tree.
- Fleet groups (early, off unless started with --fleet-groups; e.g. set ALAMO_ARGS=--fleet-groups
  before Play_Mod.cmd, or add it after Play.cmd): N groups the selected ships, U ungroups, Y locks
  a group so it moves together. No on-screen frames yet.
- Tactical HUD, galactic conquest screens, key rebinding, dialog controls.
- Thrawn's Revenge galactic conquest: winning and losing a campaign.

Changes since the 2026-11-13 build
----------------------------------
- Original squadron sizes and prices again; --squadron-size removed.
- Skirmish with more than two players, teams, per-slot AI difficulty and the advanced options.
- Land and space skirmish AI on the original's task-force, build pad, start-structure and
  target rules; Empire against Underworld land skirmish runs to its end.
- Battle-start autosave and Retry.
- Story presentation (text, hints, pointers, fades, letterbox, cameras, locks, movie crawl) and
  story rewards; Lua object-state commands (Prevent_All_Fire, Suspend_Locomotor,
  Set_Cannot_Be_Killed and others) now change the battle.
- Hardpoint turret turning, hardpoint model removal and debris, retreat jump-out, indigenous
  spawners, Magnepulse and gravity fields.
- Weather, shadow, selection circle and ability effects; ability and structure animations.
- Battle, galactic and music audio fixes.
- Frame hitch and memory growth fix; crash dumps.
- Mod stacks, base-EaW refusal, mod asset salvage, mod check report with grades.

Known gaps
----------
- Saves made with earlier test builds may not load (the save format changed again). Start new
  games.
- Galactic AI is close to the original but not the same yet: the Underworld ends up with less
  money, and the Rebels attack Shola earlier than in the original.
- Land skirmish AI: the Empire's battles still last a little shorter than in the original; in
  space the Rebels take more damage than in the original.
- Skirmish with more than two players is new and was tested with four slots; please report
  anything odd with more.
- Story presentation: the tutorial pointer is a plain 2D arrow for now.
- EAW-Remake: Single Player in its main menu does nothing yet (its menu draws Single Player as a
  heading); its space skirmish on Geonosis runs slowly (huge asteroid fields).
- Age of Legends: the skirmish setup's game-type list stops the skirmish start.
- Mods that ship shader sources (.fx) without compiled files (Thrawn's Revenge's AlamoEngine.fx,
  Fall of the Republic's terrain effect) draw those effects with the fallback, because this build
  does not compile .fx sources at run time yet; the check report lists them as shader warnings.
- Mods without a modinfo.json show their workshop id in the in-game Mods list (the Play_Mod.cmd
  menu knows the names of EAW-Remake and Age of Legends).
- Mods with 32-bit precompiled Lua scripts lose those scripts (the original 64-bit game has the
  same limit).
